# wrapdata

Wrap and reshape data text streams with deterministic transforms.

**Site:** https://theworker02.github.io/wrapdata/

## Install / run

```bash
git clone https://github.com/theworker02/wrapdata.git
cd wrapdata
node src/cli.js
node --test
```
